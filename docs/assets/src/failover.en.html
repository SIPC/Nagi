Automatic failover when a node goes down

Give a container a standby node. The original node, the standby and a witness each have one vote; only the side with two votes runs it.

Panel
Votes only, runs nothing
01Normally
The original node renews with the other two every 10 s, keeping two votes and running the container.
02Cut off
When renewals fail, it stops the container itself before the lease (30 s) expires.
03Takeover
Once the lease expires, the witness votes for the standby, which starts the container with two votes.
Only one side can hold two of the three votes, so a container never runs on two nodes at once.
