# 界面规范

面板界面的视觉和文案规范。目标：层次清楚、间距统一、措辞像正规的控制台，同时保持简单——信息不密、说明不长。

## 视觉

- **克制的工具风**（参照 OpenAI 平台、Vercel、Linear 的控制台）：白底（深色模式近黑）、灰阶为主、少用卡片，区块之间用细分隔线而不是边框盒子。彩色只用于状态：绿色正常、琥珀警告、红色错误、蓝色信息；品牌色（波浪）只用在标识上。
- **颜色只用变量**（`index.css`）：`background`、`card`、`muted`、`subtle`、`border`、`muted-foreground`、`success`、`warning`、`destructive`、`info`、`log`。不要写死 `zinc-950`、`sky-400` 这类颜色。深浅色都要能看。
- **字体**：系统字体（英文 SF / Segoe UI，中文苹方 / 微软雅黑），不打包字体文件。英文字体排在中文前面，否则英文会用中文字体里偏大的拉丁字形。
- **字号**：页面标题 24px（`text-2xl font-semibold`）；区块标题 15px 加粗；卡片标题 14px 加粗；正文 14px；辅助说明、表头、元信息 12–13px（`text-[13px]`、`text-xs`）。等宽字体只用于路径、地址、镜像、命令、ID、版本号。说明文字加 `text-pretty`，避免末行只剩一两个字。
- **间距**只用下面这几档，不用 10px、14px 这类半档（标签和输入框之间的 6px 例外）：

  | 用途 | 取值 |
  | --- | --- |
  | 图标和文字之间、标题和副标题之间 | 4px（`gap-1`） |
  | 同一行的元素、按钮之间 | 8px（`gap-2`） |
  | 监控块之间、卡片内各块之间、行内的字段和按钮之间 | 12px（`gap-3`） |
  | 卡片内边距、卡片之间、表单字段之间、区块标题到内容 | 16px（`gap-4`、`p-4`） |
  | 区块之间（分隔线上下各一次，`Section` 自带下方那次，父级用 `grid gap-6`） | 24px |
  | 页面标题到内容 | 32px（`PageHeader` 自带） |

  区块和表格不加左右内边距，和页面标题左对齐。页面左右边距窄屏 16px、平板 24px、桌面 40px。
- **卡片只用在概览网格**：项目列表、节点列表用卡片（`CardGrid` + `Card`/`cardClass`、`CardHeader`、`CardBody`、`CardFooter`，每张至少 18rem，四边内边距 16px）；项目卡片最多列 5 个容器，多的显示“还有 N 个”。其余内容（容器、快照、渠道、接入码……）一律是无框的列表或表格。监控数值块用 `Tile`（浅底、无边框、不可点），放在 `TileGrid` 里，按所在区域的宽度自动排列，不按窗口宽度写断点。
- **表单**：区块里的表单用 `FormBody`（最宽 42rem），两个字段一行时用 `FormRow`（等宽）；底部按钮用 `FormActions`，在表单宽度内靠右，主要操作在最后，“已保存”之类的提示紧挨在按钮左边。只有一个字段时可以字段和按钮同一行。`SettingRow` 里的按钮跟在右栏控件下面。独立表单的输入框 36px 高，表格里的行内输入框 32px。
- **表格**：行高 44px；快照、版本、部署记录这类长列表用 `<Table compact>`（40px）。区块以表格结尾时，下一个区块的分隔线就是最后一行的底线（`Section` 自动处理，表格要是区块内容的最后一项，最多包一层 div）。窄屏上次要的列用 `hidden sm:table-cell` 收起，不要横向滚动。
- **圆角**：卡片、对话框 10px（`rounded-lg`），输入框、按钮 7px（`rounded-md`），徽标 5px。

## 布局

- **左侧竖排导航**（`AppLayout`）：顶部标识，中间 项目 / 节点 / 设置，底部用户名、主题切换、退出。窄屏（< 768px）改为顶部一行。内容区最宽 1024px。
- **详情页**：`Breadcrumb` 上级链接 → `PageHeader`（标题、状态、元信息、操作）→ `Tabs` → 内容。当前标签记在地址的 `tab` 参数里。
- **项目页**分三块：概览（容器表、全部容器的资源合计和端口映射的请求监控；各容器的监控在容器页的概览里）、网络、设置，记在地址的 `tab` 参数里。点一个容器进入**容器页**（`/projects/<项目>/c/<容器>`，当前标签记在 `view` 参数里），标签：概览、配置、版本、日志、终端、数据（快照、顶替、备份节点、更换节点）。删除容器在容器页标题右侧的 ⋯ 菜单里。
- **三栏**：宽屏（≥ 1280px）的项目页始终是 导航 / 项目栏 / 内容（`ProjectSplit`）。项目栏列出概览、各个容器（状态、节点、当前 CPU 和内存）、网络、设置，选中的一项显示在右边；点另一个容器时保留当前标签。右边不显示上级链接和项目页的标签，概览里也不再重复容器表（只保留添加和部署按钮）。窄屏没有项目栏，改用标签页和上级链接。
- **切换动画**：只动 opacity 和 transform，不超过 220ms，缓动 `cubic-bezier(0.23, 1, 0.32, 1)`。项目栏的选中背景滑到新选中项；右边换内容时上移 6px 淡入（`animate-pane-in`），换标签时只淡入（`animate-fade-in`）。系统开启“减弱动态效果”时只保留淡入。
- **设置页**：左侧二级菜单（面板访问、账号安全、告警、备用面板、接收移交、Mesh），右侧是选中的一组；单项设置用 `SettingRow`（左侧名称和说明，右侧控件，行之间分隔线）。

## 组件（`components/ui.tsx`、`pages/layout.tsx`）

| 组件 | 用途 |
| --- | --- |
| `PageHeader` | 页面标题、一行描述、`meta`（元信息行）、右侧操作 |
| `Breadcrumb` | 详情页顶部的上级链接 |
| `Tabs` | 页面内的标签页（下划线样式） |
| `Section` | 页面上的一个区块（无边框，上方分隔线）：`title`、一句 `description`、`help`（问号提示）、右侧 `actions`；放表格时用 `flush`；危险操作用 `tone="danger"` |
| `SettingRows` / `SettingRow` | 设置项列表：左侧 `label`、`description`、`help`，右侧控件 |
| `Field` | 表单字段：`label`、一行 `hint`（格式说明）、`help`（详细说明，收进问号） |
| `Check` | 带文字的复选框，可带 `help` |
| `Segmented` | 两三个选项之间切换 |
| `FormBody` / `FormRow` / `FormActions` | 区块里的表单：限宽、两列字段、底部靠右的按钮 |
| `Table` / `Th` / `Td` | 表格；首尾单元格不留内边距，和区块标题左对齐；长列表用 `compact` |
| `CardGrid` / `Card` / `CardHeader` / `CardBody` / `CardFooter` | 概览网格里的卡片；整张是链接时给 `Link` 用 `cardClass` |
| `TileGrid` / `Tile` | 监控数值块 |
| `Status` | 状态点加文字（运行中、离线……） |
| `Badge` | 小标记（草稿、有状态、本面板……），`tone` 区分含义 |
| `Notice` | 提示条：`tone` 为 `info`、`warning`、`danger`、`success`，可带 `title` 和 `actions` |
| `Alert` | 错误提示（`Notice tone="danger"` 的简写） |
| `Empty` / `EmptyRow` | 页面级 / 区块内的空状态 |
| `KeyValue` | 两列的属性列表 |
| `CodeBlock` | 命令、密钥、地址，`copy` 时带复制按钮 |
| `LogBox` | 日志和命令输出 |
| `Loading` / `Spinner` | 加载中 |

按钮：主要操作用默认样式（每个区块最多一个）；次要操作 `outline`；行内操作、取消 `ghost`；危险操作 `destructive` 或 `destructive-outline`。区块里的按钮用 `size="sm"`。

## 文案

- **正式、简洁的控制台用语**。不用"你"，不用口语（"挂了""搬过去""凑够""不用管"），不用感叹、不用表情符号（✅ ❌ ⚠）。
- **标题和按钮用名词短语或动宾短语**：「备份节点」「立即同步」「删除项目」，不写成句子。
- **描述最多一句**，说明这个区块做什么；细节、原理、注意事项放进 `help` 问号里。字段旁边的 `hint` 只写格式（例如"格式：节点端口:容器端口"）。
- **状态用固定的词**：运行中、已停止、重启中、异常、未部署、在线、离线、同步中、待批准。
- **确认框**：第一句说要做什么，第二句说后果。例如：「删除项目 shop？项目内的所有容器和容器组将被删除，容器目录保留。」
- **成功提示**简短：「已保存」「已复制」「已发送测试消息」。错误信息直接显示接口返回的内容。
- **数字和单位之间留空格**：10 分钟、30 秒、4 MB。占用条旁的短格式例外（6.2MB、0.3%），以保持对齐。
- **数值提示用「当前 / 上限」**，单位一致，不写成句子：「CPU 0.3% / 1200%」「内存 6.0 MB / 15.5 GB」，而不是「CPU 0.3%，上限 12 核」。
- **路径示例用占位符**：「默认：<项目根目录>/<项目名>/<容器名>」。
- 术语统一：项目、容器、容器组、节点、面板、项目内网、项目连接、网络名、端口映射、快照、备份节点、顶替、热备、见证人、迁移、部署、版本、草稿。

## 多语言

界面支持中文和英文，中文是基准。

- **选择顺序**：浏览器里记住的选择（`localStorage` 的 `lang`）→ 账号保存的语言（登录后，浏览器里没有选过时采用，例如换了设备）→ 浏览器的语言偏好（`navigator.languages`，中文以外的都显示英文）。导航底部、登录页右上角的按钮切换语言，刷新页面后生效；登录后同时保存到账号（`AuthService.SetLanguage`，`users.language`）。
- **前端文案**放在 `web/src/i18n/zh/<命名空间>.ts`，英文在 `en/` 下同名文件，结构必须一致（`satisfies`，少一条 `tsc` 报错）。每个页面或组件一个命名空间，通用的状态词、按钮、时间单位在 `common`。代码里 `import { t } from "@/i18n"` 后直接用 `t.<命名空间>.<键>`，模块顶层的常量里也可以用。带参数的写成函数，句子里夹着链接等元素的写成返回 JSX 的函数（文件用 `.tsx`）。日期用 `lib/utils` 的 `formatDateTime` / `formatDate` / `formatTime`，不直接调 `toLocaleString()`。`pnpm -C web check:i18n` 检查有没有写死的中文，确实需要的行尾加 `// i18n-ignore`。
- **面板返回的文字**：前端请求都带 `Accept-Language`（终端的 WebSocket 用 `lang` 参数），面板按它返回错误信息和操作过程的输出。Go 代码里照常写中文，返回给浏览器的错误用 `i18n.Errorf` / `i18n.New`（`spec.Invalid` 已经是），过程输出用 `i18n.T(ctx, …)`，英文译文登记在 `internal/pkg/i18n/en.go`，`go test ./internal/pkg/i18n` 检查有没有漏。日志不翻译。节点返回的信息、告警消息、已保存的部署记录目前还是中文。
- **英文文案**：简洁的控制台用语，标题和按钮用句首大写（「Delete project」「Sync now」），不用感叹号，少用 please。术语：项目 project、容器 container、容器组 container group、节点 node、面板 panel、主面板 primary panel、备用面板 standby panel、项目内网 project network、项目连接 project link、网络名 network name、端口映射 port mapping、快照 snapshot、备份节点 backup node、顶替 failover、热备 hot standby、见证人 witness、迁移 migration、部署 deployment、版本 version、草稿 draft、接入码 invite code、移交 handover。
