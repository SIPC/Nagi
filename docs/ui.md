# 界面规范

面板界面的视觉和文案规范。目标：层次清楚、间距统一、措辞像正规的控制台，同时保持简单——信息不密、说明不长。

## 视觉

- **克制的工具风**（参照 OpenAI 平台、Vercel、Linear 的控制台）：白底（深色模式近黑）、灰阶为主、少用卡片，区块之间用细分隔线而不是边框盒子。彩色只用于状态：绿色正常、琥珀警告、红色错误、蓝色信息；品牌色（波浪）只用在标识上。
- **颜色只用变量**（`index.css`）：`background`、`card`、`muted`、`subtle`、`border`、`muted-foreground`、`success`、`warning`、`destructive`、`info`、`log`。不要写死 `zinc-950`、`sky-400` 这类颜色。深浅色都要能看。
- **字号**：页面标题 24px（`text-2xl font-semibold`）；区块标题 15px 加粗；正文 14px；辅助说明、表头、元信息 12–13px（`text-[13px]`、`text-xs`）。等宽字体只用于路径、地址、镜像、命令、ID、版本号。
- **间距**：区块之间一条分隔线，线上下各 24px（`Section` 自带）；表单字段之间 16px（`gap-4`）；同一行的按钮之间 8px。区块和表格不加左右内边距，和页面标题左对齐。
- **卡片只用在概览网格**：项目列表、节点列表用卡片；其余内容（容器、快照、渠道、接入码……）一律是无框的列表或表格。
- **圆角**：卡片、对话框 10px（`rounded-lg`），输入框、按钮 7px（`rounded-md`），徽标 5px。

## 布局

- **左侧竖排导航**（`AppLayout`）：顶部标识，中间 项目 / 节点 / 设置，底部用户名、主题切换、退出。窄屏（< 768px）改为顶部一行。内容区最宽 1024px。
- **详情页**：`Breadcrumb` 上级链接 → `PageHeader`（标题、状态、元信息、操作）→ `Tabs` → 内容。当前标签记在地址的 `tab` 参数里。
- **项目页**分三块：概览（容器表、全部容器的资源合计和端口映射的请求监控；各容器的监控在容器页的概览里）、网络、设置，记在地址的 `tab` 参数里。点一个容器进入**容器页**（`/projects/<项目>/c/<容器>`，当前标签记在 `view` 参数里），标签：概览、配置、版本、日志、终端、数据（快照、顶替、备份节点、更换节点）。删除容器在容器页标题右侧的 ⋯ 菜单里。
- **三栏**：宽屏（≥ 1280px）的项目页始终是 导航 / 项目栏 / 内容（`ProjectSplit`）。项目栏列出概览、各个容器（状态、节点、当前 CPU 和内存）、网络、设置，选中的一项显示在右边；点另一个容器时保留当前标签。右边不显示上级链接和项目页的标签，概览里也不再重复容器表（只保留添加和部署按钮）。窄屏没有项目栏，改用标签页和上级链接。
- **切换动画**：只动 opacity 和 transform，不超过 220ms，缓动 `cubic-bezier(0.23, 1, 0.32, 1)`。项目栏的选中背景滑到新选中项；右边换内容时上移 6px 淡入（`animate-pane-in`），换标签时只淡入（`animate-fade-in`）。系统开启“减弱动态效果”时只保留淡入。
- **设置页**：左侧二级菜单（面板访问、账号安全、告警、备用面板、接收移交、Mesh），右侧是选中的一组；单项设置用 `SettingRow`（左侧名称和说明，右侧控件，行之间分隔线）。

## 组件（`components/ui.tsx`、`pages/layout.tsx`）

| 组件 | 用途 |
| --- | --- |
| `PageHeader` | 页面标题、一行描述、`meta`（元信息行）、右侧操作 |
| `Breadcrumb` | 详情页顶部的上级链接 |
| `Tabs` | 页面内的标签页（下划线样式） |
| `Section` | 页面上的一个区块（无边框，上方分隔线）：`title`、一句 `description`、`help`（问号提示）、右侧 `actions`；放表格时用 `flush`；危险操作用 `tone="danger"` |
| `SettingRows` / `SettingRow` | 设置项列表：左侧 `label`、`description`、`help`，右侧控件 |
| `Field` | 表单字段：`label`、一行 `hint`（格式说明）、`help`（详细说明，收进问号） |
| `Check` | 带文字的复选框，可带 `help` |
| `Segmented` | 两三个选项之间切换 |
| `Table` / `Th` / `Td` | 表格；首尾单元格不留内边距，和区块标题左对齐 |
| `Status` | 状态点加文字（运行中、离线……） |
| `Badge` | 小标记（草稿、有状态、本面板……），`tone` 区分含义 |
| `Notice` | 提示条：`tone` 为 `info`、`warning`、`danger`、`success`，可带 `title` 和 `actions` |
| `Alert` | 错误提示（`Notice tone="danger"` 的简写） |
| `Empty` / `EmptyRow` | 页面级 / 区块内的空状态 |
| `KeyValue` | 两列的属性列表 |
| `CodeBlock` | 命令、密钥、地址，`copy` 时带复制按钮 |
| `LogBox` | 日志和命令输出 |
| `Loading` / `Spinner` | 加载中 |

按钮：主要操作用默认样式（每个区块最多一个）；次要操作 `outline`；行内操作、取消 `ghost`；危险操作 `destructive` 或 `destructive-outline`。区块里的按钮用 `size="sm"`。

## 文案

- **正式、简洁的控制台用语**。不用"你"，不用口语（"挂了""搬过去""凑够""不用管"），不用感叹、不用表情符号（✅ ❌ ⚠）。
- **标题和按钮用名词短语或动宾短语**：「备份节点」「立即同步」「删除项目」，不写成句子。
- **描述最多一句**，说明这个区块做什么；细节、原理、注意事项放进 `help` 问号里。字段旁边的 `hint` 只写格式（例如"格式：节点端口:容器端口"）。
- **状态用固定的词**：运行中、已停止、重启中、异常、未部署、在线、离线、同步中、待批准。
- **确认框**：第一句说要做什么，第二句说后果。例如：「删除项目 shop？项目内的所有容器和容器组将被删除，容器目录保留。」
- **成功提示**简短：「已保存」「已复制」「已发送测试消息」。错误信息直接显示接口返回的内容。
- **数字和单位之间留空格**：10 分钟、30 秒、4 MB。占用条旁的短格式例外（6.2MB、0.3%），以保持对齐。
- **数值提示用「当前 / 上限」**，单位一致，不写成句子：「CPU 0.3% / 1200%」「内存 6.0 MB / 15.5 GB」，而不是「CPU 0.3%，上限 12 核」。
- **路径示例用占位符**：「默认：<项目根目录>/<项目名>/<容器名>」。
- 术语统一：项目、容器、容器组、节点、面板、项目内网、项目连接、网络名、端口映射、快照、备份节点、顶替、热备、见证人、迁移、部署、版本、草稿。
