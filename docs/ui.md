# 界面规范

面板界面的视觉和文案规范。目标：简约精致，一眼看懂。**易懂是高级的前提**，宁可朴素，也不要为了好看牺牲清楚。

## 依据

- **组件全部用 shadcn/ui**（`components.json`：new-york 风格、neutral 配色），尺寸、配色、字重取官方源码，图表用 shadcn Charts。不用 Geist 或其他设计系统的组件和取值。
- **布局原则**参考苹果 HIG（它没有单独的网页规范，用的是 Layout 等通用章节）：按重要性从上到下排，对齐和缩进表达层级，用留白、形状或线条分组时只选一种，细节渐进展开。
- **主题调轻**：组件结构和变体用 shadcn 的，主题层按下面调，比默认更轻、更紧凑，其他不改：
  - `--radius` 从 0.625rem 调到 0.5rem，Card 用 `rounded-lg`（官方是 `rounded-xl`）。
  - 字重三档：CSS 的 400 用 MiSans Normal（正文），500 用 MiSans Regular（强调），600 用 MiSans Medium（只用于页面、区块和对话框标题）。
  - 按钮、输入框、下拉高 32（官方默认 36），手机 40。
  - 卡片、按钮、输入框不用阴影。导航和内容同一底色（不用 `sidebar` 灰底），搜索无边框。
  - 表格行间无线，悬停整行浅底；表头 13 号次文字；左右外扩 8，文字和区块标题对齐。
  - 概览卡片内边距 16、间距 12（官方 24）；图表不套 Card。
  - 提示没有框和图标，警告用一个琥珀色小点。

## 视觉

### 三条总则

1. **所有数值都从下面的表里取。** 不要新增半档，不要为某一页单独调。要例外先改本文。
2. **常态黑白灰，颜色留给要处理的事。** 绿、琥珀、红、蓝只表示状态。品牌色只用在 logo 和对外流量的图形上。状态不能只靠颜色，旁边总有文字。
3. **能不用框就不用框，层次靠字号和间距。** 框会打断连续性。只有能点的卡片（项目、节点）、输入控件和浮层才有框；图表、数值块、提示条都不要框，内容直接贴齐页面左右边缘。没有框以后，用四级标题和「组内近、组间远」分层：大区块之间一条细线，线上下各 32。

### 间距

只用 4、8、12、16、24、32、48。

| 取值 | 用途 |
| --- | --- |
| 4 | 标题和说明、标签和数值、导航项之间、卡片内的容器行之间 |
| 8 | 同一行的按钮，字段名到输入框，表格单元格内边距，图表卡片内部各行 |
| 12 | 卡片内各组之间，图表标题到图形 |
| 16 | 区块标题到内容，分组标题到内容，卡片内边距，卡片之间，表单字段之间，设置行上下 |
| 24 | 标题区到内容，标签之间，对话框内边距，数字到图表 |
| 24 | 区块分隔线的上下 |
| 32 | 页面边距，并排的图表和数值块之间 |
| 48 | 设置页二级菜单到内容 |

### 圆角

`--radius: 0.5rem`，其余按 shadcn 的公式算。

| 档位 | 取值 | 用途 |
| --- | --- | --- |
| `rounded-sm` | 4 | 菜单项、复选框 |
| `rounded-md` | 6 | 按钮、输入框、下拉、菜单、导航项、标签触发器 |
| `rounded-lg` | 8 | 卡片、对话框、标签列表、日志框 |
| `rounded-full` | 全圆 | 徽标、头像、状态点 |

不用 `rounded-xl` 和更大的圆角。

### 字体和字号

- **字体**：MiSans（小米，中英文数字一套），打包进面板，不依赖外部网络。用 npm 包 `misans` 的切片 woff2，浏览器按 `unicode-range` 只下载用到的部分；Normal、Regular、Medium 三种字重约 5.6 MB。系统字体作回退。数字一律等宽对齐（`tabular-nums`）。小米的许可允许嵌入软件，条件是在软件中注明使用了 MiSans，所以版本更新页底部和 README 都写了署名。
- **等宽字体**：系统等宽字体，只用于路径、地址、镜像、命令、ID、版本号。

| 字号 | 用途 |
| --- | --- |
| 24 / 600 | 页面标题（`tracking-tight`） |
| 24 / 500 | 全局概览的关键数字 |
| 20 / 500 | 数值块和端口映射的数字 |
| 16 / 600 | 区块标题、对话框标题、项目栏的项目名 |
| 14 / 500 | 分组标题、卡片标题、字段名、主按钮 |
| 14 / 400 | 正文、说明、次要按钮、标签、导航、表格 |
| 13 / 400 | 等宽文字、表头、图表标题（次文字色） |
| 12 / 400 | 徽标、图例、坐标轴、占用数字 |

最小 12。

### 颜色

只用变量（`index.css`），不写死色值，深浅色都要能看。灰阶是 shadcn neutral 主题。

| 变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `background` | `#ffffff` | `#0a0a0a` | 页面 |
| `card` | `#ffffff` | `#171717` | 菜单、提示等浮层。概览卡片不用它，和页面同一底色，只留边框 |
| `muted`、`accent` | `#f5f5f5` | `#262626` | 悬停、选中、标签列表 |
| `border`、`input` | `#e5e5e5` | 白 10%、15% | 边框 |
| `foreground` | `#0a0a0a` | `#ededed` | 主文字 |
| `muted-foreground` | `#737373` | `#a1a1a1` | 说明 |
| `primary` | `#171717` | `#e5e5e5` | 主按钮、进度条 |
| `destructive` | `#e7000b` | `#ff6467` | 错误、危险操作 |
| 成功 | `#16a34a` | `#4ade80` | |
| 警告 | `#f59e0b` | `#fbbf24` | 文字用 `#b45309` |
| 信息 | `#2563eb` | `#60a5fa` | |
| 品牌 | `#3f9cc6` | `#6db9dc` | logo、对外流量 |

焦点：边框变 `ring` 色，外加 3px `ring/50`（`:focus-visible`），不能只靠改文字颜色。

### 控件

| 组件 | 规则 |
| --- | --- |
| `Button` | 高 32，`px-3`，图标按钮 32×32，14 号；主按钮 500，其余 400，无阴影。变体：`default`、`outline`、`ghost`、`destructive` |
| 主按钮 | 一个区域最多一个，**只在有事要做时出现**。例如容器页平时没有主按钮，有草稿时才出现「部署草稿」。危险操作放进 ⋯ 菜单或确认框 |
| `Input`、`Select` | 高 32，`px-3`，1px 边框，无阴影。出错时红色边框，错误写在字段下面。字段名 14 / 500，到输入框 8 |
| `Tabs` 默认样式 | 切换视图（`Segmented`）：列表高 32、`bg-muted`、内边距 3，选中白底加 1px 描边。**只放 2 到 3 项，再多用下拉**，时间范围用下拉 |
| `Tabs variant="line"` | 页面内的标签：高 40，选中是主文字加 2px 下划线，未选中是次文字，14 / 400，间距 24 |
| `Badge` | 全圆，`px-2`，12 / 400。常用 `outline`；草稿这类用警告色文字；危险用 `destructive` |
| 状态 | 6px 圆点加文字。多行内容里点和第一行（名称）对齐，不对整块上下居中；第二行缩进到名称起点 |
| 禁用 | 只有确实做不了时才置灰，并说明原因。不要因为没填写就禁用提交，提交后在字段旁提示 |
| 手机（< 768px） | 按钮、输入框高 40，字号 16（iOS 聚焦不缩放），导航项高 44 |

### 表格（`Table`）

表头高 36、13 号次文字，表头下一条线。行高 36，列宽跟内容走，靠左排，多出来的宽度留给最后一列，第一列是深色，其余是灰色。单元格左右 8、上下 4，行操作用无框按钮（左右 8），多行内容的行顶部对齐，**行之间没有线**，悬停整行 `bg-accent`、首尾圆角 6。表格左右各外扩 8，文字和区块标题对齐。数字等宽。窄屏收起次要列，不要横向滚动整页。

### 卡片（`Card`）

只有概览网格用卡片（项目、节点）：内边距 16，`rounded-lg`，1px 边框，底色和页面相同，无阴影。每张至少 240 宽，卡片之间 16，内容区最宽时**一行 4 张**。

- 标题 14 / 500 和状态同一行，副标题紧贴标题（间距 4）。
- 容器行之间 4；点、名称、徽标、节点名四列，节点名靠右对齐成一列。
- 底栏贴底，内容多少不同的卡片底栏也在同一条线上。
- 标题放不下的徽标移到副标题那一行，不要把名称挤成两行。
- 节点卡片的占用：CPU、内存、磁盘上下三项，间距 12。每项上面是 13 号灰色名称和靠右的「已用 / 总量」（已用 500，总量灰色），下面是占满整行、高 4 的占用条。条平时是 `primary` 色，75% 起琥珀，90% 起红，已用同步变色。底栏 13 号灰字。

### 提示（`Alert`）

一行内容，**没有框和底色**，14 号，贴齐页面左右边缘，警告用一个琥珀色小点开头。标题 500，说明次文字。右边最多一个按钮。同一处只放一条，多条合并成一行「需要处理 3 项」，点开看。错误用错误色文字。

### 镜像更新提示

镜像有新版本时不在页面里放提示条，分三处：

- **容器外**：项目栏和项目卡片的容器名后面一个 14px 的蓝色向上箭头（`CircleArrowUp`，悬停显示「镜像可更新」）。
- **项目概览**：页头加一个带箭头的次要按钮「更新 N 个容器」，悬停列出镜像。
- **进入可更新的容器**：右下角弹窗（宽 340，内边距 16，`rounded-lg`，`shadow-lg`），写明镜像和后果（拉取新镜像并重建容器，服务短暂中断），按钮是「稍后」「更新容器」，右上角可关闭。不自动消失，不抢焦点。容器标题旁同时有一个「可更新」徽标，弹窗关掉以后点它重新打开。

规则：

- 关掉后按「容器 + 镜像新版本」记在浏览器里，同一版本不再自动弹，出现更新的版本时再弹。切换标签不重复弹。
- 只读成员和备用面板上不弹，也不显示「更新容器」，但箭头保留。
- 面板和节点的更新提示也在右下角，同时出现时往上叠，间距 8。
- 手机上弹窗在底部，左右各留 16，宽度撑满。
- 手机上的容器细分页：灰色的列全部并进第二行（路径 · 大小 · 时间），可以折行，右边只留操作；网络的状态因为要一眼看到，留在第一行右边。行高 60，单行 44，行内无框按钮高 40，文字 14。标签可以横向滑动，选中项滚到可见。进入文件页后标题栏换成返回、卷名、更多，不再显示容器标题和标签；编辑文件的标题栏是取消、文件名、保存。⋮ 打开底部操作面板（`Drawer`），项高 44；确认框和表单也从底部出现，底部按钮等宽撑满。需要处理的提示把主按钮放到文字下面，撑满。问号在手机上点按显示。

### 对话框（`Dialog`、`AlertDialog`）

`rounded-lg`，内边距 24，间距 16，标题 16 / 600，说明次文字，按钮靠右（取消在前，动作在后）。危险操作的默认焦点在取消上；表单对话框的默认焦点在第一个输入框（不落在问号上，免得说明一打开就盖住标题）。按钮和上面的内容隔 24，靠留白分组，不加底栏和分隔线。有按钮时不显示右上角的关闭，取消就是关闭；没有按钮的对话框才有关闭，次文字色，悬停变主文字。

所有浮层（对话框、确认框、菜单、下拉、提示、Toast、右下角提示、图表提示）用同一种表面：`popover` 底色（浅色白，深色 `#171717`，比页面高一层），不加边框，靠底色和 `shadow-popover` 阴影浮起来（阴影里带一圈很淡的描边，深色下也看得出边缘），实色不透明。遮罩只压暗（浅色 30%、深色 60% 黑），不模糊，背后的页面保持清楚。有框按钮底色透明，放在浮层里不会出现一块页面底色。深色下危险按钮的底色用 `#dc2626`，白字对比度够。

### 监控图表（shadcn Charts，规划）

用 shadcn 的 `chart` 组件（基于 Recharts，新增依赖 `recharts`），替换现在自己画的 `TimeChart`。内容不能比线上少，也不能堆砌。

| 项目 | 规则 |
| --- | --- |
| 容器 | **不要框**，每个数值块、每张图各自独立，并排时间隔 32，靠留白分开，不合并成一块 |
| 数值块（`Tile`） | 名称、当前值（20 / 500）、无坐标轴的小折线。**不显示峰值**，避免和当前值重复。线用次文字色，线宽 1.5，没有坐标轴 |
| 图表 | 标题（13 号次文字色，让图形做主角）和图例在一行，下面是图形和 5 个时间。**不画背景网格线，不要纵坐标**，具体数值看上面的数字和悬停提示；高 112 |
| 线和柱 | `type="monotone"` 平滑曲线，线宽 1.5，无渐变、无面积填充。柱子堆叠，柱间留缝 |
| 图例和提示 | `ChartLegend`、`ChartTooltip`：10px 方块（圆角 2）。提示框鼠标移上去才出现，`rounded-lg`、12 号，数值等宽右对齐，带虚线定位 |
| 配色 | 正常用灰：2xx、入站、平均。异常带色：4xx 琥珀、5xx 红、P95 琥珀、P99 红。P50、3xx 用蓝，出站用品牌色 |
| 占用指示 | 16px 圆环（SVG 自己画，shadcn 没有这么小的圆环），`primary` 色，75% 起琥珀，90% 起红，旁边总有数字 |

**端口映射**（项目概览）固定是：请求、错误率、平均耗时、P95 耗时、入站流量、出站流量六个数字，加请求数（按状态码堆叠）、耗时（平均、P50、P95、P99）、流量三张图。都不要框。

**流量桑基图**（全局概览，规划）：

- 左边发出，右边接收，每个节点和「外部网络」都单独显示，不合并，两边顺序相同，同一节点两边高度相同。
- 纯色细线，不用渐变。对外流量用品牌色，节点之间用灰色。
- **每条线起点直接写去向和速率**（如「外部网络 3.1 MB/s」），不用顺着线找。
- 线宽 = `max(2, √(KB/s) × 0.24)`，只表示大致大小，准确数字看标注。
- 不要框，铺满内容区，左右和其他内容对齐：左边的名称靠左，右边的名称靠右。按实际宽度计算布局，不要整体缩放，文字不能小于 12。
- 节点很多时默认只显示流量最大的路径，其余合并成「其他」，阈值实现时定。
- shadcn Charts 没有合适的桑基图样式（要在线上直接标注），用 SVG 自己算布局。

### 对齐

- **右边缘要齐**：一个区块的内容铺满内容区，不要有的到头、有的中途停下。
- 表头线和分隔线不超出内容区；表格外扩 8 只是为了悬停底色。
- 无框按钮放在边上时外扩 12，文字贴齐内容边缘。
- **列数固定，不留单独掉行的一张**：端口映射的数字 6 列，数值块 4 列，图表 3 列；窄屏（< 768px）分别是 3、2、1 列。三列图表的标题和图例分两行，图形才对得齐。
- 控件管什么就放在什么旁边：时间范围放在它影响的区块标题旁，不放页头。

### 动画

按 [HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：动效要有用途、简短、随时能打断，高频操作尽量少加；信息不能只靠动效表达。

| 场景 | 动效 | 时长 |
| --- | --- | --- |
| 点导航、标签、切换控件后的内容 | 跟导航同方向滑入 32px：竖排选了下面的，内容从下方进入；横排选了右边的，内容从右边进入。透明度比位移先到（120ms），才看得见移动。旧内容同方向移开 16px 并淡出。手机主导航只淡入淡出 | 进 300ms，出 100ms |
| 进下一级、第一次显示、骨架换成内容、提示出现 | 淡入 | 160ms |
| 菜单、下拉 | 淡入，从触发位置放大 3%；关闭时淡出 | 120ms / 100ms |
| 对话框 | 淡入，放大 3%；关闭时淡出 | 200ms / 100ms |
| 手机底部面板 | 从底部滑入，从底部退出 | 220ms / 160ms |
| 标签和切换控件的选中指示器；主导航、设置菜单、项目栏的选中底色 | 从上一项滑过去：朝移动方向的边先到，另一条边跟上，中途略微拉长 | 200ms / 340ms |
| 占用条的数据变化 | 长度变化 | 220ms |
| 实时流量图切换视图、路径增减 | 不滑动，图留在原地：新路径从两端所在的行长出来，消失的路径收回所在的行（淡出在前半段，淡入在后半段），其余的换位。和下面内容用同一条曲线。路径断流后显示 0 B/s，保留 30 秒再收起，避免小流量反复改变布局 | 360ms |
| 数据加载完、列表增减引起的高度变化 | 每个组件各自过渡到新高度，下面的内容跟着移动（`AutoHeight`，区块和标签内容自带）。变高时新露出的部分渐隐（最长 200px），不留裁切线，原有内容不变暗；变矮时不裁切。不过渡整页，改变窗口大小时也不过渡 | 360ms |
| 切换选项后多出、少掉的一块（选「指定」后的勾选列表，`Collapse`） | 高度和透明度一起过渡，下面的内容跟着移动；收起时内容留到过渡结束才移除，不先消失再收拢。切换控件换内容（`Slide`）时高度过渡在换内容那一层外面，下面的内容同样平滑移动 | 360ms |
| 会变的数据（监控数字、占用、速率、数量、已运行时长、最近在线） | 只有变了的那几位上下滚动，变大从下面滚上来，变小从上面滚下来，从右往左依次错开 16ms（`Roll`）。每一位的宽度也过渡，位数或单位变化时后面的内容平滑让位。第一次显示不滚 | 260ms |
| 复制变成对勾 | 图标缩放淡入 | 180ms |
| 展开「更多设置」 | 内容从上方滑入，箭头旋转 | 240ms |
| 切换主题 | 整页交叉淡化 | 200ms |
| 状态点的颜色变化 | 过渡 | 300ms |
| 颜色变化（悬停等） | 过渡 | 150ms |

- **材质**：只有手机吸顶栏用 `material`（82% 底色加模糊），透出下面滚过的内容。浮层一律实色（见「对话框」），遮罩不模糊。系统要求减弱透明度时吸顶栏也是实色。
- **悬浮和选中**：导航项悬浮用 `accent` 的 50%，选中用 `accent` 实色，一眼能分开。
- **按下**：按钮按下时不透明度 80%，立即生效，不做动画。
- 只动 opacity 和 transform；选中滑块例外，要动两条边，它是绝对定位，不影响其他元素。
- 内容滑入用 `cubic-bezier(0.25, 0.46, 0.3, 1)`。其他进入用 `cubic-bezier(0.23, 1, 0.32, 1)`，退出用 `cubic-bezier(0.4, 0, 1, 1)`，退出比进入快。
- 动画不挡操作：进入时就能点，不等动画结束。
- **减弱动态效果**：`--motion` 为 0，所有位移和缩放归零，只剩淡入淡出；指示器直接跳到位。
- **不滑动**：时间范围和日志筛选。图表和日志还是同一份内容，只是范围变了。
- **不做**：按钮按下缩放、列表依次入场、加载完成的装饰动画。这些是高频或纯装饰，HIG 不建议。

## 布局

- **页面起点**：导航 240 宽，内容靠左，**不居中**，最宽 1120，页面边距 32。列表页和设置页的标题都从 272 开始；项目页多一列项目栏（280 宽），标题从 552 开始。窄屏（< 768px）导航收成顶部一行，页面边距 16。
- **导航**：左上角只有 logo（保留品牌色，名称只给读屏）。下面是搜索（Ctrl/⌘ + K，无边框，和导航项同样的样式）、概览 / 项目 / 节点 / 日志 / 设置，节点上有离线数量，日志只给管理员。底部是用户（头像、显示名称、角色），点开是个人资料、账号安全、主题（浅色、深色、跟随系统）、语言和退出。导航和内容同一底色，只隔一条细线。标签页标题显示当前页面。
- **标题区**：页面标题和状态在左，操作在右，下面一行说明或元信息（间距 4）。操作最多一个主按钮、一两个次要按钮和 ⋯ 菜单。
- **全局概览**（`/overview`）：导航第一项。从上到下是：节点在线、容器运行中、项目、对外入站、对外出站、节点之间六个数字；实时流量（桑基图，可切换全部 / 对外 / 节点之间）；流量趋势（对外、节点之间，时间范围放在这个区块的标题旁，上面的实时内容不受它影响）；节点表；流量最大的端口映射。每 10 秒更新。数据来源见 [monitoring.md](monitoring.md#全局概览)。
- **项目列表**：标题；提醒合并成一条；筛选和排序一行；卡片。筛选和排序写进地址。
- **项目页三列**：宽屏（≥ 1280px）是 导航 / 项目栏 / 内容。项目栏顶部从上到下是「项目」（13 号次文字）、项目名（16 / 600）、状态和网络名（13 号次文字）。项目栏列出概览、各个容器（第一行状态点、名称、节点，第二行 CPU 和内存的占用圆环）、网络、设置，选中的一项显示在右边；点另一个容器时保留当前标签。窄屏没有项目栏，改用标签页和上级链接。
- **项目概览**：页头是「更新 N 个容器」（有更新时）、部署全部容器和 ⋯ 菜单。下面一个「监控」区块，时间范围放在它的标题旁，同时管下面所有内容；区块里是全部容器合计（4 个数值块）和各端口映射的请求和流量，用 14 / 500 的分组标题分开，组之间一条细线。容器的有状态等属性写在元信息行，不用徽标贴在「概览」旁边。项目栏里已有容器列表，宽屏不重复容器表；「添加容器」放在项目栏容器标题旁。
- **容器页**（`/projects/<项目>/c/<容器>`，当前标签记在 `view` 参数里）：标题（设了显示名称时是显示名称，后面用灰色等宽字写容器名）、状态和「可更新」徽标（有更新时），右边是重启容器（已停止时是启动）、重新部署，重命名、停止、删除在 ⋯ 菜单里。标签：概览、日志、终端、配置、版本、网络（端口映射、内部访问地址）、存储（卷、文件、快照）、高可用（顶替、备份节点、更换节点）。旧地址 `?view=data` 跳到存储。启动、停止、重启不重建容器，不生成版本；设置了顶替的容器不能停止，菜单项置灰并说明要先取消顶替。
- **容器概览**：一排关键信息（镜像、节点、版本、已运行、目录）；资源（4 个数值块，单一服务时不重复名称，容器组按服务分组）；最近事件（连续相同的操作合并，如「保存草稿 4 次」）。不放只有一行的状态表。
- **节点组网图**：网络和高可用两个视图沿用 `node-map`：紧凑居中，面板是最上面的方块，和节点围成一圈；网络图的连线都是直线（中转的线经过面板），高可用图的箭头向外弯；节点带图标、占用外圈和状态点，名字和说明写在圆的外侧，连线上有胶囊标注。
- **节点详情、设置各页、项目设置、项目网络**：和容器细分页一样用列表行和状态在前的写法；设置项是「设置行」，一行状态加一个按钮，表单放进对话框或展开一行。
- **状态表**：设计稿「状态」分组列出每页代码里的全部状态分支。加载一律用区块内骨架（比内容矮，默认两行、每行 36，内容出来时过渡到实际高度），不用大块留白的 Spinner；查询失败一律红字加重试，不留空白。
- **新建项目**：对话框（宽 440），只填名称；网络名由名称生成，显示在下面一行灰字，点「修改」才变成输入框。创建后进入项目概览，还没有容器时监控区块照常排版但没有数据，内容本身加模糊（`filter: blur`，不用 `backdrop-filter`，后者会在盒子边缘留下截止线），居中写「暂无容器」和「添加容器」按钮，第一个容器也要点添加。「第一个容器」不再放在新建项目的表单里。
- **添加容器**：项目栏容器标题旁的加号或空概览的按钮进入，占整个主区，不再和项目概览混在一页。表单单列限宽 672、靠左。顺序是类型（容器、容器组，管理员还有「现有目录」，见 [agent.md](agent.md#现有目录)）、镜像、名称和节点、端口映射和持久化目录、环境变量、更多设置、按钮。名称留空时取镜像名，节点默认是项目里容器最多的在线节点，所以只填镜像就能提交。启动命令、工作目录、容器目录、依赖、内存和 CPU 上限、健康检查收在「更多设置」，有值时展开。容器组是名称和节点、compose 编辑器，更多设置里是容器目录和依赖。按钮靠左：添加并部署、仅添加、取消。环境变量一行两个输入框，和上面的两列对齐，眼睛按钮在值的输入框里，只有名称像密钥的才有。字段说明一律放问号，格式写在占位符里。手机上单列，按钮撑满。
- **列表行**：容器细分页不用宽表格，也不要表头。一行是主信息（可带一行 13 号灰字）、靠右对齐的灰色短信息、操作（一个主操作，或者更多 `DropdownMenu`），深色只留给主信息和操作。单行高 36，两行高 52，设置行高 40，悬停整行变底色。状态写成灰字，不用徽标；等宽字体只给摘要、文件内容和终端。对齐规则：灰色信息用固定宽度的列，同一页的各个列表共用一套列位，数字靠右，时间和状态靠左；所有内容对齐第一行的基线，字号统一 14，只用颜色分主次；无框按钮的文字和更多的图标贴齐页面右边，和标题栏的有框按钮同一条线。设置行（一行状态加一个有框按钮）上下居中。区块说明放进标题旁的问号，不占一行。
- **容器 · 存储**：卷、快照两个区块。单个容器的卷标题写容器内路径（卷名是按路径自动起的，不显示）；应用文件那一行标题是「应用文件」，没有文件也没挂进容器时不显示。卷的第二行写路径和文件数，或者「配置里已不再使用」「外部卷，不在快照范围」「部署后生效」，右边是大小（统计不完整时前面加 `>`）和最后修改，主操作是浏览，取消挂载放在卷的文件页右上角的更多里。标题栏右边写节点磁盘剩余和「添加目录」，输入框点了才出现。快照一行写绝对时间加相对时间、类型、版本、大小和更多（恢复、删除），默认 6 条；「部署前数据」只能删除，「版本文件」的操作位写「随版本回滚」。标题栏右边写快照间隔、份数上限、修改和「创建快照」。部署、快照的操作输出显示在页面最上面。
- **文件管理**：在存储标签里就地换内容，不开对话框，顶部是面包屑「存储 / 卷名 / 目录」，可以直接链接和后退。右边是来源（当前文件或某个快照）、上传、更多（新建目录、下载此目录、取消挂载）。一行是图标、名称、大小、时间和更多（下载、编辑、删除）；快照里是下载和恢复两个操作。编辑文件（文本且不超过 1 MiB）也是整页，面包屑多一级，右边是取消、保存。删除、上传重名、恢复才用确认框，带「先做一份快照」。
- **容器 · 版本**：一行是版本号，后面跟灰字（当前、来源或结果），右边是镜像摘要前 8 位（完整值在 title）、部署时间、回滚。回滚确认框对比当前版本和目标版本；「同时恢复数据」放在框里，默认不勾，勾选后确认按钮变红。查询失败要显示错误，不能留空表。
- **容器 · 网络**：对外访问、内部访问两个区块。对外访问第一行是访问地址（可点），第二行是「名称 → 目标 · 入口 · 证书或协议」，右边是状态（正常、解析不符、证书失败、未生效）。出错时才加第三行说明和主操作（重试、编辑），查看原因、编辑、删除在更多里。添加和编辑映射用对话框（宽 520），字段写在问号里，只有多入口证书的提醒直接显示。内部访问一行一个地址加复制。修改内部端口只在项目网络。
- **容器 · 高可用**：先看状态，设置放进对话框。默认是顶替、备份节点、所在节点三行，每行写当前状态和一个操作（设置、迁移）。顶替和备份节点互斥，做不了的一行写原因，没有按钮。设置顶替的对话框只露节点、见证人和两个开关，目录和租约时长收在「高级设置」。需要处理时最上面一条提示带主按钮（确认顶替、从最新快照恢复）；已设置的那项展开成标签值列表，可恢复的快照用列表行，恢复目录在确认框里。节点离线时「重新部署」是红字按钮，确认框写清数据不跟过去。
- **节点 · 终端、文件**：只有管理员能看到，备用面板上没有（[node-access.md](node-access.md#界面)）。进入前先验证身份（`requireElevation`，15 分钟内不再询问）。终端打开过以后切到别的标签不断开；连接后状态旁一直写 `root · 节点名`；手机上终端上方一行等宽按键（Esc、Tab、方向键、Ctrl）。文件页和卷的文件管理同一种写法：面包屑从「根目录」开始，右边是上传、更多（转到路径、新建目录、新建文件、在此打开终端、下载目录）；一行是图标、名称、大小、时间和更多，名称后用灰字写「禁止访问」「只读」「敏感」，属主和权限在悬停提示里。编辑页右边是属主和权限、更多（历史版本）、取消、保存；发现冲突时提示右边是「使用节点内容」，点保存确认覆盖。
- **容器 · 终端**：顶部左边是连接状态，右边是「连接」（连过后是「重新连接」），连接前不显示黑框。运行的服务多于一个时加下拉，切换会重连。终端框最小高 640。
- **项目网络**：全部端口映射的总览、项目内网、内部端口、项目连接。
- **节点页**有卡片、网络、高可用三种视图（切换控件，记在地址的 `view` 参数里），「移交给其他面板」放进 ⋯ 菜单。后两种是拓扑图（`NodeMap`，纯 SVG）：面板在最上面，和节点围成一圈，两种图里位置相同。节点外圈是 CPU、内存、磁盘里占用最高的一项（阈值同占用指示）。窄屏（< 640px）只用卡片。
  - **网络**：线条是在线节点之间的 mesh 连接。直连是灰色实线（向外弯，不穿过面板），经面板中转是琥珀色虚线并经过面板，不可达是红色点线，只有出问题的连接带颜色。悬停或聚焦节点时突出它的连接并显示延迟，点击进入节点页。
  - **高可用**：箭头从容器所在的节点指向热备（实线）或备份节点（虚线），标出容器数；节点下面写有状态、没有副本的容器数。点选（悬停预览）一个节点模拟它故障：图下按结果分组列出它上面的容器（自动顶替、确认后顶替、无法顶替、可从备份恢复、数据无法恢复、无状态可重新部署），以及把它当作热备或备份节点的容器。判断按 [failover.md](failover.md) 的规则和当前的在线情况：顶替要热备和见证人都在线。
- **设置 · 关于**：所有角色都能看。上面是品牌、一句介绍、当前运行的版本号和版本状态（管理员点了进版本更新）；下面是项目链接（源代码、更新记录、反馈问题、开源许可）和致谢。MiSans 的署名放在致谢里，是字体许可的要求，不能省。
- **日志页**（`/activity`）：面板上的操作和告警，标题右边是「全部 / 操作 / 告警」分段控件，下面一行一条。以前在设置里，旧地址 `/settings?tab=activity` 跳到这里。
- **设置页**：左侧二级菜单按组排：我的账号（个人资料、账号安全）、面板（面板访问、成员、告警、版本更新、备用面板）、节点（接收节点、节点网络）。不是管理员时只有我的账号。右侧是选中的一项。设置行（`SettingRow`）左边名称和说明，右边最多两个控件，行之间一条线。主密钥放在面板访问，不放账号安全；修改密码用对话框；登录设备默认显示 3 条；账号安全最后是「访问令牌」（MCP 地址一行加令牌列表，生成令牌和令牌只显示一次都用对话框，见 [mcp.md](mcp.md#登录)）。OAuth 授权页（`/oauth/authorize`）和登录页同一种外框，上面写客户端名称和回调地址的域名，权限选项默认都不勾，按钮是等宽的「拒绝」「允许」。成员列表参考 Apple「用户与群组」和 Vercel 的成员页：一行只放身份，头像（32）、名称（显示名称，没有时是用户名），第二行灰字写用户名、角色和限定的访问范围；右边只在开了两步验证时写状态，然后是 ⋯（36，不外扩，离行底色右边缘 16）。整行上下居中。改角色和访问范围都在 ⋯ 的「编辑权限」对话框里，项目、节点各一个「全部 / 指定」分段控件，指定时下面列出可勾选的项。
- **状态写进地址**：筛选、排序、标签、视图、时间范围都写进地址，刷新和分享不丢。导航和跳转用真正的链接，能 Ctrl+点击在新标签打开。

## 组件（`components/ui.tsx`、`components/confirm.tsx`、`pages/layout.tsx`）

交互组件统一用 shadcn/ui（基于 Radix）：源码在 `components/ui/`。页面继续从 `@/components/ui` 引用下表的组件；新增组件也先看 shadcn 有没有，不要自己写弹层或图表。

| 组件 | 用途 |
| --- | --- |
| `PageHeader` | 页面标题、一行描述、`meta`（元信息行）、右侧操作 |
| `Breadcrumb` | 窄屏详情页顶部的上级链接 |
| `Tabs` | 页面内的标签页（`variant="line"`） |
| `Section` | 页面上的一个区块（无边框）：`title`、一句 `description`、`help`（问号提示）、右侧 `actions`；危险操作用 `tone="danger"` |
| `SettingRows` / `SettingRow` | 设置项列表：左侧 `label`、`description`、`help`，右侧控件 |
| `Field` | 表单字段：`label`、一行 `hint`（格式说明）、`help`（详细说明，收进问号）、`error`、`required` |
| `Check` | 带文字的复选框，可带 `help` |
| `Segmented` | 2 到 3 个选项之间切换（`Tabs` 默认样式） |
| `FormBody` / `FormRow` / `FormActions` | 区块里的表单：限宽 42rem、两列字段、底部靠左的按钮，和字段左对齐 |

| `Status` | 状态点加文字（运行中、离线……） |

| `Dialog` | 带表单或内容的对话框（shadcn Dialog） |

| `Select` | 下拉选择（shadcn Select），写法和原生 select 一样：`<option>` 作子元素 |
| `confirmAction` / `ask` / `notify` | 确认框和提示（shadcn AlertDialog），`action` 写具体动作。不用浏览器的 `confirm`、`alert` |
| `ButtonLink` | 外观是按钮的链接，不要在 `Link` 里套 `Button`；只读时置灰，只是跳转的加 `readOnlyOk` |
| `EnvEditor` | 环境变量编辑器：一行一个变量，像密钥的值默认隐藏，可切到文本批量编辑 |
| `ConfigDiff` | 草稿相对当前版本的改动 |
| `useUnsaved` | 表单有未保存的修改时，离开前确认 |
| `toast`（sonner） | 操作结果的轻提示，显示在顶部中间 |
| `VolumeFiles` | 卷的文件管理，在存储标签里就地显示（`pages/volume-files.tsx`） |
| `Notice` | 提示条（shadcn Alert）：`tone` 为 `info`、`warning`、`danger`、`success`，可带 `title` 和 `actions` |
| `Alert` | 错误提示（`Notice tone="danger"` 的简写），在表单里出现时焦点移过来；用户接着要改输入时加 `keepFocus` |
| `Empty` / `EmptyRow` | 页面级 / 区块内的空状态 |
| `KeyValue` | 属性列表 |
| `CodeBlock` | 命令、密钥、地址，`copy` 时带复制按钮 |
| `LogBox` | 日志和命令输出 |
| `Loading` / `Spinner` | 加载中 |

## 文案

- **正式、简洁的控制台用语**。不用"你"，不用口语（"挂了""搬过去""凑够""不用管"），不用感叹、不用表情符号（✅ ❌ ⚠）。
- **标题和按钮用名词短语或动宾短语**：「备份节点」「立即同步」「删除项目」，不写成句子。
- **描述最多一句**，说明这个区块做什么；细节、原理、注意事项放进 `help` 问号里。字段旁边的 `hint` 只写格式（例如"格式：节点端口:容器端口"）。
- **状态用固定的词**：运行中、已停止、重启中、异常、未部署、在线、离线、同步中、待批准。节点离线时容器的状态是未知，不是已停止：项目和容器显示「节点 n2 离线」，容器状态表显示「状态未知」；导航的「节点」上有离线数量，项目列表顶部有提示。
- **确认框**：第一句说要做什么（到第一个问号，作为标题），第二句说后果。例如：「删除项目 shop？项目内的所有容器和容器组将被删除，容器目录保留。」主按钮写具体动作（「重启」「删除容器」），不写「确定」。会重建容器或丢数据的操作都要确认；危险操作的默认焦点在「取消」上；删除数据且无法恢复时要输入名称。
- **成功提示**简短，用 Toast 显示：「已保存」「已复制」「已发送测试消息」。错误信息直接显示接口返回的内容。
- **数字和单位之间留空格**：10 分钟、30 秒、4 MB。占用条旁的短格式例外（6.2MB、0.3%），以保持对齐。
- **数值提示用「当前 / 上限」**，单位一致，不写成句子：「CPU 10% / 1600%」「内存 6.0 MB / 15.5 GB」。节点卡片的 CPU 按每核 100% 累加，其余页面显示占整机的百分比。
- **路径示例用占位符**：「默认：<项目根目录>/<项目名>/<容器名>」。
- 术语统一：项目、容器、容器组、节点、面板、项目内网、项目连接、网络名、端口映射、跨节点入口、入口节点、快照、备份节点、顶替、热备、见证人、迁移、部署、版本、草稿。

## 多语言

界面支持中文和英文，中文是基准。

- **选择顺序**：浏览器里记住的选择（`localStorage` 的 `lang`）→ 账号保存的语言（登录后，浏览器里没有选过时采用，例如换了设备）→ 浏览器的语言偏好（`navigator.languages`，中文以外的都显示英文）。导航底部的用户菜单、登录页右上角的按钮切换语言，刷新页面后生效；登录后同时保存到账号（`AuthService.SetLanguage`，`users.language`）。
- **前端文案**放在 `web/src/i18n/zh/<命名空间>.ts`，英文在 `en/` 下同名文件，结构必须一致（`satisfies`，少一条 `tsc` 报错）。每个页面或组件一个命名空间，通用的状态词、按钮、时间单位在 `common`。代码里 `import { t } from "@/i18n"` 后直接用 `t.<命名空间>.<键>`，模块顶层的常量里也可以用。带参数的写成函数，句子里夹着链接等元素的写成返回 JSX 的函数（文件用 `.tsx`）。日期用 `lib/utils` 的 `formatDateTime` / `formatDate` / `formatTime`，不直接调 `toLocaleString()`。`pnpm -C web check:i18n` 检查有没有写死的中文，确实需要的行尾加 `// i18n-ignore`。
- **面板返回的文字**：前端请求都带 `Accept-Language`（终端的 WebSocket 用 `lang` 参数），面板按它返回错误信息和操作过程的输出。Go 代码里照常写中文，返回给浏览器的错误用 `i18n.Errorf` / `i18n.New`（`spec.Invalid` 已经是），过程输出用 `i18n.T(ctx, …)`，英文译文登记在 `internal/pkg/i18n/en.go`，`go test ./internal/pkg/i18n` 检查有没有漏。日志不翻译。节点返回的信息、告警消息、已保存的部署记录目前还是中文。
- **英文文案**：简洁的控制台用语，标题和按钮用句首大写（「Delete project」「Sync now」），不用感叹号，少用 please。术语：项目 project、容器 container、容器组 container group、节点 node、面板 panel、主面板 primary panel、备用面板 standby panel、项目内网 project network、项目连接 project link、网络名 network name、端口映射 port mapping、跨节点入口 cross-node entry、入口节点 entry node、快照 snapshot、备份节点 backup node、顶替 failover、热备 hot standby、见证人 witness、迁移 migration、部署 deployment、版本 version、草稿 draft、接入码 invite code、移交 handover。
